# HUBサーバーの変更について

**マイクラHUBサーバーは、年に一度、投票によって変更します。**

かめぱわ～るどマイクラサーバーの顔となる部分ですので、投票によってみんなの意見を反映させる形になります。

具体的には、以下の通りです。

- 大規模改修について
    - 製作者を変える大規模な改修を、大規模改修とする。
    - 大規模改修は、年一回、4月1日に、投票で行う。
    - その投票の候補は、みんなが行けるように設定した単発鯖に置く。
    - その候補をサーバーユーザーが見て回り、決定する。
- 小規模改修について
    - 使用中のHUBの、ゲートの位置とスポーンからゲートまでの道を変えない、同じ製作者による小規模な改修（季節の変更等）を、小規模改修とする。
    - 小規模改修は、製作者が自由なタイミングで作ることができる。
    - 改修案を作った後に、そのHUBに変えるかどうかを投票で決める。
    - HUBを新しく作りたい場合は、管理者が把握するために、プロジェクトとして申請し、参加者が増える場合は都度報告する。
    - HUBについて話し合うロール限定チャンネルを新たに作り、HUBについての話し合い等は必ずそちらで行うようにする。
