# かめぱわぁ〜るど 遊びかたガイド

## このページについて

かめぱわぁ〜るどは、Minecraftを中心に **「みんなで面白いことをやる」** コミュニティ。
ガチガチの攻略サイトではなく、初めて来た人が「今日はこれやってみようかな」と思える案内所を目指しているよ。

> 迷ったら、まずは気になるイベントにふらっと参加でOK。見学だけでも大歓迎！

このページ自体も Markdown からできているので、文章を書くときはデザインを気にしなくて大丈夫。
見出し・表・引用・コードなどが、自動でこの雰囲気に変わる。

### イベントにはどうやって参加する？

1. Discord の「イベント」から遊びたい企画を開く
2. **興味あり**を押しておく
3. 開始時間になったらボイスチャンネルへ！

サーバー内でコマンドを使う企画なら、こんなふうに案内を書くこともできる。

```text
/event join
あとは集合場所で待っててね！
```

## はじめて遊ぶ人へ

最初から全部を覚える必要はなし。まずはこの3つだけで十分！

- **あいさつしてみる** — 雑談チャンネルで「はじめまして！」だけでも◎
- **ひとつ参加してみる** — イベントは途中参加できるものもたくさん
- **わからなかったら聞く** — 古参メンバーがたぶん教えてくれる

> **ポイント:** かめぱわぁ〜るどでは「上手いこと」より、一緒に面白がってくれることのほうが大事。

### 持ちもの

基本は Minecraft Java Edition があればOK。企画によって導入するものが違うときは、イベントページに書いてあるよ。

## よくある質問

### 毎週参加しないとダメ？

ぜんぜん大丈夫。気になる企画がある週だけでも、数か月ぶりでも歓迎！

### ボイスチャットは必須？

聞き専OKの企画も多いよ。イベントごとの説明を確認してね。

### 自分でもイベントを開ける？

もちろん。小さい遊びでも大歓迎。「これやりたい！」を持ち込んで、一緒に形にしよう。
