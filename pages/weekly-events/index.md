# ウィークイベントとは

毎週替わりのイベントのことです。

基本的に毎週日曜日から土曜日を1スパンとして行っています

VCで行う普段の毎日のように行っているイベントとは違い、その週はずっとその中期イベントをやっていて、みんなで記録を競い合ったり、協力して建築をしたりします！

競い合うイベントは週末にその記録のランキングがDiscordで公開されます！

ウィークイベント用の雑談チャットがあります→[**週替わりイベント雑談**](https://discord.com/channels/930083398691733565/1419259214005796875)

ここではランキングの発表を行ったり、イベントについての議論や雑談を行ったりします

また専用のロールがあります。週替わりイベントをプレイしたい人、興味のある人はぜひつけてみてください！→[ロールの付け方](/role-setup) 

## イベント例

畑クラフト：種を植えて植えて植えて…育てた数を競い合う！

アスレチックイベント：一週間でアスレチックを極めよう！タイムを競うよ

釣り大会：大きな魚を釣り上げて記録を競い合おう！

鉱石ポイントバトル：鉱石を掘りまくってポイントを競う！

街づくり建築：みんなで街づくりをしよう！
