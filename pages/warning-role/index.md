# 警告ロール

- 一発banには値しないような違反や、違反したが反省、改善が見られる場合に付けるロールです。
- レベルが1〜3まであり、違反をするたびにレベルが上がっていきます。レベルが４を超える状態になると、banになります。
- 違反や反省の度合いによって付くレベルが変わります。違反が発覚した場合、管理者が違反者と話し、その度合いを判断します。
- 同じ違反を繰り返したり、改善が見られない場合は、通常より厳しい処罰になる場合があります
