# 動画・配信の撮影や投稿に関するガイドライン

1. **撮影していいのは基本マイクラサーバーのみ**
撮影を行なっていいのはマイクラサーバーのみです。DiscordのチャットやVCは基本撮影（または録音）はしないようにしましょう。（処罰対象になる可能性もあるので絶対にやめてね 
2. **撮影する時は、他の参加者への配慮や思いやりを大切に**
中には動画や配信に載りたくない人もいるはずです。周りの他参加者にチャットの表示や動画撮影などの許可を得た上で、配慮や思いやりを意識しながら、やっていきましょう！
3. **投稿や配信をする時は、必ずクレジット表記を**
投稿する際は、かめぱわぁ〜るどで撮影したことを示すクレジット表記を掲載してください。
かめぱわぁ〜るどの存続と繁栄のためにもご協力のほどお願いします。
（例）
今配信しているサーバーはこちら
[https://discord.gg/kamepower](https://discord.gg/kamepower)
4. **Discordアカウントと配信するプラットフォームのアカウントの連携および表示を忘れずに**
誰がこの動画や配信をしているのかを運営が把握するために、Discordアカウントおよび配信するプラットフォーム（YouTubeなど）のアカウントの連携およびそれらの表示は必須です。Discordアカウントと配信するプラットフォームのアカウントの連携（紐付け）を忘れずに行ないましょう。
なおDiscordの設定から、連携が可能となっております。そして運営がそれらを確認できるよう、表示にしておきましょう。
（諸般の事情により、表示ができない場合はチケットまでお問い合わせしてください。）
5. **運営の指示に従おう！**
サーバーにプラスであれば運営はできる限りサポートしますが、場合によっては、運営から動画や配信アーカイブの削除や非公開などの指示がくる可能性がございます。必ず運営の指示に忠実に協力してください！（指示に従わない場合は処罰の対象になる場合がございます。絶対に協力してね‼️）
6. **撮影時声出しする場合はカスタムVCなどを使用し、チャンネルステータスを設定すること**
声出しにより動画撮影や配信を行なう場合は、必ずカスタムVCなどを使用し、ステータスに「YouTube配信中」など、使用用途がわかるステータスに設定すること。（万が一声が載っちゃったなどのトラブルを避けるために実施する対策です。）

その他ガイドラインに関するお問い合わせは、管理者まで。
