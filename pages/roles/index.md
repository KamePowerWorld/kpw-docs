# ロール一覧

- 一般のロール
    - 雑談勢
    - 技術雑談

    - 作業厨
    - 朝からVCしたい
- 通知ロール
    - イベント予定通知
        - [**イベント予定**](https://discord.com/channels/930083398691733565/1246103208154103888)で通知を受け取れます。
    - イベント通知
        - イベント開始時などに、通知を受け取れます。→[イベントについて](/events)
    - マイクラ通知
        - [**マイクラお知らせ**](https://discord.com/channels/930083398691733565/942025528410521631)の通知を受け取れます。
    - 運営からのお知らせ通知
        - 運営からの、重要度が低めのお知らせの通知を受け取れます。
    - かめすたが来た！
        - かめすたさんがVCに来た際に、通知を受け取れます。
        - かめすたさんと話したい人はつけてみましょう。
    - 部活動発足通知
        - 部活動が新しくできたときに、通知を受け取れます。→[部活動制度](https://app.notion.com/p/2069951c945381199457c8ee706a96ac?pvs=21)
        - 色々な部活動に入ってみたい人は、つけましょう。
    - PJ発足通知
        - 新たなプロジェクトが発足された時に、通知を受け取れます。→[プロジェクト制度 (廃止)](https://app.notion.com/p/2069951c94538178b9b1ef29b9e78173?pvs=21)
        - 現在はつけることができません。
    - 生活鯖
        - 生活鯖の募集などのメンションを受け取れます。
        - マイクラ生活鯖で遊んでいる人は、つけてみましょう。
- 特殊なロール
    - 常連
        - サーバーによく来ている人に付きます。→[常連ロールとは](/regular-role)
        - 一か月ごとに更新されます。
    - かめすた認証
        - かめすたさんに気に入られると付きます。
    - ~~RA-YA認証~~
        - ~~らーやさんに気に入られると付きます。~~
    - イベント参加した
        - イベントに参加すると自動で付きます。
    - 最近イベント参加した
        - 最近イベントに参加した人に自動で付きます。
    - 最近めっちゃイベント参加した
        - 最近イベントにめっちゃ参加した人に自動で付きます。
    - リンク済み
        - マイクラ鯖にリンクさせると付きます。→[**マイクラの入り方**](https://discord.com/channels/930083398691733565/934501574011662417)
    - 統合版申請済
        - マイクラ鯖と統合版のリンクを申請すると付きます。→[**マイクラの入り方**](https://discord.com/channels/930083398691733565/934501574011662417)
    - 警告Lv1、警告Lv2、警告Lv3
        - サーバーのルールに違反すると付きます。
        - 警告３がついた状態で違反すると、banされます。→[**サーバールール**](https://discord.com/channels/930083398691733565/930087215780991036)
